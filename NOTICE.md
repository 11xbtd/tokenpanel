## Bundled data

### Vendor brand icons

`src/renderer/lib/brands.ts` is generated by `scripts/build-brands.mjs` from
[@lobehub/icons-static-svg](https://github.com/lobehub/lobe-icons)
(`@lobehub/icons-static-svg`, MIT), which collects publicly published brand
marks. The generated file embeds the SVG path data as inline `data:` URIs, so
the plugin renders vendor marks offline.

Copyright (c) LobeHub and contributors. MIT License.

Trademark ownership is unaffected: each vendor logo remains the property of
its respective owner and is used here only to identify that vendor's service
inside a local dashboard. This project is not affiliated with, endorsed by, or
sponsored by any of the vendors listed.

Providers without a reliable public mark in that set (currently `zcode-plan`
and the generic `custom-http` source) fall back to a letter chip instead of a
substituted logo.

### token-monitor / tokscale

Local client log path discovery and adapter coverage research were informed by
<https://github.com/Javis603/token-monitor> and
<https://github.com/junhoyeo/tokscale> (both MIT). No source code is bundled
from either project.

### New API

Product concepts and public API response shapes were referenced from
<https://github.com/QuantumNous/new-api>, which is licensed under AGPL-3.0
with additional attribution terms. **No source code from new-api is copied
into this project.** Only independently implemented ideas and publicly

### Other references

Balance/usage endpoint lists and dashboard patterns were cross-checked against
CodexBar, api-monitor, tokscale and token-monitor (see README links). Their
licenses apply to their own code; none is bundled here.

### zstddec

`zstddec` is used to decode DeepSeek Harness zstd session logs in both the
browser server and uTools' Node 20 runtime. The package embeds a WebAssembly
Zstandard decoder.

<https://github.com/donmccurdy/zstddec>
